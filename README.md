# OUTREACH by LeoLend

Home for LeoLend's custom outreach apps. Right now it holds the brand kit only; apps get added under `apps/`.

- `brand/tokens.css` — colours, fonts, radius as CSS variables. Every app imports this.
- `brand/tokens.json` — the same values for non-CSS use (email builders, scripts).
- `brand/BRAND.md` — usage rules and the required legal line.
- `brand/logo-round.png` — the LLG lion mark, transparent (use this). `brand/logo.png` is the original on white; `brand/icon.png` is the small mark.
- `index.html` — branded placeholder page.
